# Shiva Kumar Souta — Portfolio

This is my personal portfolio website built with **React** and **Tailwind CSS**, showcasing my skills, projects, and experience as a software developer and AI/ML enthusiast. It features a bold **Neo-Brutalism** design style that reflects modern web aesthetics while maintaining professional clarity.

---

## Features

- **Neo-Brutalism Design**: Bold, high-contrast aesthetic with thick borders, hard shadows, and vibrant colors
- Responsive, mobile-first design
- Interactive UI with smooth hover effects
- Projects section with live links and source code
- Contact form integration using EmailJS
- Smooth scrolling with navbar offset
- Back to top button
- Modern styling with Tailwind CSS v4

---

## Tech Stack

- **Frontend**: React 18.2.0
- **Styling**: Tailwind CSS v4.3.3
- **Email**: EmailJS
- **Icons**: React Icons + Devicon
- **Notifications**: React Hot Toast
- **Build Tool**: Vite 4.5.14
- **Fonts**: Space Grotesk (primary)

---

## Design System

### Neo-Brutalism Color Palette
- **Background**: Cream Yellow (#FEF9E7)
- **Card Background**: White (#FFFFFF)
- **Primary Accent**: Yellow (#ffde59)
- **Secondary Accent**: Mint Green (#72D6A3)
- **Hover/Link Accent**: Dark Yellow (#facc15)
- **Borders**: Pure Black (#000000, 3px)
- **Text**: Black (#000000)

### Key Design Elements
- Thick 3px black borders on all elements
- Hard drop shadows (2px-4px offset, no blur)
- Rounded corners (8px-16px for softness)
- Bold typography (Space Grotesk font)
- High contrast for maximum readability
- Interactive hover effects with shadow offset
- Smooth scrolling with sticky navbar
